# 装修编辑器验收清单

适用对象：`component-library-standalone`（组件库右侧抽屉，**代码已交付**）与 `decoration-editor-toolkit`（装修器效率增强，**代码已交付，2026-11-12**）。

使用方式：逐条按「操作」执行，核对「预期」，在 `[ ]` 内打勾；不通过请在备注列写明现象与复现步骤。A 部分通过后回填 `openspec/changes/component-library-standalone/tasks.md`（对应编号已标注），B 部分在 toolkit 实施完成后执行，回填其 `tasks.md` §7.1/§7.2。

判定口径：`通过` = 预期全部成立；`不适用` 必须写明原因（如环境缺权限账号），不得以推测充数；`不通过` 需登记并回到对应 change 修复。

## A. 前置交付验收：`component-library-standalone`

### A0 全局外观

- [ ] **A0.1**〔侧边栏修复〕进任一装修编辑器页，点「收起菜单」

  - 预期：收起态列宽 88px，图标完整居中不被裁切；切换有平滑过渡；展开态仍为 210px

- [ ] **A0.2**〔tasks 2.6 / spec 三栏布局〕打开任一页面的装修编辑器
  - 预期：左栏为页面结构树且独占全高（无组件库常驻段），中栏内容编辑，右栏实时预览；顶栏保存草稿 / 发布 / 下线可见

### A1 抽屉位置与可用性〔tasks 2.6〕

- [ ] **A1.1** 点左栏头部「组件库」按钮
  - 预期：抽屉**从右侧滑出**，宽约 480px，贴着实时预览栏；不遮顶栏；标题「公共组件库」

- [ ] **A1.2** 抽屉打开状态下拖动抽屉左边框
  - 预期：可调宽；抽屉仍在 `.ed-body` 内，不溢出到顶栏

- [ ] **A1.3** 抽屉打开状态下点击左栏结构树另一个节点、在中栏修改表单、点顶栏「保存草稿」
  - 预期：三处均可操作（无遮罩锁死）；抽屉内「模块插入：页面顶层第 N 位」提示随选中节点更新
  - 备注：这是 `modal=false + modal-penetrable=true` 的核心判据

- [ ] **A1.4** 抽屉打开状态下点抽屉外区域 / 点关闭按钮
  - 预期：抽屉关闭，实时预览恢复可读，页面内容不变化

### A2 真实预览与懒渲染〔tasks 2.6 / 5.4〕

- [ ] **A2.1** 打开抽屉，查看首屏可见的模块卡片
  - 预期：显示官网同源真实渲染（版式、字体、配色一致），不是 CSS 示意图；卡片下方有名称与「分组 · type」

- [ ] **A2.2** 打开浏览器网络面板，浏览精选产品 / 最新资讯 / 产品网格 / 资讯流 / FAQ 列表等数据驱动模块
  - 预期：出现内置占位样例（示例产品、示例资讯、示例 FAQ），**不发起 `cms.*` 内容接口请求**

- [ ] **A2.3** 滚动抽屉列表，用开发者工具观察卡片挂载
  - 预期：仅可视区（含 120px 预取）卡片执行真实渲染，未进入可视区的显示「效果预览」占位；滚过后不再重复挂载

- [ ] **A2.4** 查看基础元素分组（标题 / 文本 / 图片 / 按钮）
  - 预期：按原比例渲染（非 1240px 缩放），卡片高度 88px 且不与相邻卡片重叠

- [ ] **A2.5**〔tasks 5.4 性能基线〕抽屉内连续滚动全部 20+ 组件，用性能面板记录一次
  - 记录：首屏可见卡片数 `___`、滚动帧率 `___ fps`、堆内存峰值 `___ MB`、与懒渲染首屏对照结论 `___`

### A3 插入与判据〔tasks 2.6 / spec 从组件库插入〕

- [ ] **A3.1** 选中一个顶层模块后点某模块卡片
  - 预期：模块以默认内容插入选中项之后；结构树出现新节点；中栏定位到新节点；**抽屉自动关闭**、右栏预览即时显示

- [ ] **A3.2** 选中一个可装载子内容的模块（如 hero）后点基础元素卡片
  - 预期：元素插入该模块 `children` 末尾，结构树出现缩进子节点，节点数 +1

- [ ] **A3.3** 选中数据驱动模块后浏览基础元素
  - 预期：基础元素卡片显示不可用原因（如「该模块不接受子内容」），点击无效，草稿不变

- [ ] **A3.4** 用**只有内容查看权限**的账号打开抽屉
  - 预期：显示「只读模式」提示；真实效果可浏览；全部卡片禁用不可插入；顶栏「草稿未保存」标签不出现

- [ ] **A3.5** 构造接近上限的页面（节点 400 / 深度 4 / 单模块子内容 50）后尝试插入
  - 预期：插入被拒绝并提示已达上限；结构树与预览不变

- [ ] **A3.6** 在插入被拒绝后调整选中项或换一个组件再次插入
  - 预期：抽屉保持打开、原因提示可读；成功后才自动关闭

### A4 端到端闭环〔tasks 5.2〕

- [ ] **A4.1** 打开抽屉 → 插入一个模块 → 在中栏改标题 → 「保存草稿」

- [ ] **A4.4** 点「下线」

### A5 回归与命令〔tasks 5.3 / 5.5 / 5.1〕
