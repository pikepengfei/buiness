# website-preview-fidelity

装修预览保真：组件库效果与编辑器实时预览改由**同源隔离宿主**承载，与目标页面在版式、间距、字体、颜色、尺寸、交互态、响应式与内容上**逐项一致**；响应式按**所选设备视口**判定，草稿变更即时同步且幂等。

> 修的是一条长期存在的隐性缺陷：官网样式被写在 `<style scoped>` 里 `@import`，Vite 先内联、Vue 再加 `data-v`，于是对子组件渲染出的区块**一条都不匹配**——预览一直是「无样式裸 HTML + 后台字体」。实测编辑页命中首屏模块的 20 条规则全部带 scoped 属性，不带属性的 0 条。

## 实测差异（修复前 → 隔离宿主实测）

| 观测项 | 官网 | 预览现状 | 隔离宿主 |
| --- | --- | --- | --- |
| 首屏模块上下内边距 | 96px | **0px** | 96px |
| 首屏模块背景 | `rgb(248,245,240)` | **透明** | `rgb(248,245,240)` |
| 内容容器最大宽度 | 1240px | **无限制** | 1240px |
| 正文字体 / 行高 / 颜色 | 官网字体 / 25.6px / `rgb(22,22,22)` | 后台字体 / `normal` / 黑 | 与官网一致 |
| 主标题（1280 视口） | 54px / 800 | **32px / 700** | 54px / 800 |
| 窄窗口下的桌面版式 | 桌面多列 | **误判为移动版式** | 按设备宽度真实判定 |

宿主可行性已在运行中的浏览器里探针验证：宽 1280px 得到官网全部数值，改 500px 后 640 断点命中、内边距 64px、主标题 34px，改回 1280px 完整恢复；后台自身按钮与字体不受影响。单宿主样式环境构建 50ms。**跨文档共享 constructed stylesheet 被浏览器拒绝**（`NotAllowedError`），该优化路径已在 design 中记为否决方案。

## 在全链路中的位置

- 前置：`component-library-standalone`（已交付，真实渲染卡片 + 右侧抽屉 + 三栏）与 `decoration-editor-toolkit`（已交付，模板库标签页 + 拖拽批量 + 卡片可选内容入口）
- 本 change **只替换预览承载方式**：卡片 DOM 契约、`pick` 事件、抽屉 tabs、插入判据、上限护栏、模板复用入口全部不变；模板缩略因此自动获得同样保真度
- 与 `site-runtime-link-integrity` 无文件冲突（不碰路由、不碰官网前台渲染实现）
