# decoration-editor-toolkit

装修器效率增强：区块拖拽排序、复制、跨页复用、区块模板库与批量操作。

## 在全链路中的位置

第 3 步，排在 `page-publication-approval` 之后（两者都改 `editor.vue`；跨页复制写草稿时必须沿用审批状态的自动失效规则）。数据模型 `{id,type,visible,props}` 与前台渲染均不改动，因此不依赖路由迁移，只依赖它已建立的「发布才可见」。

## 关键交付物

- `specs/block-decoration/spec.md` — 排序、复制、跨页复用、模板、默认内容、兼容保护、批量操作（7 项要求 / 20 个场景）
- `design.md` — 9 项决策：为何用原生 HTML5 拖拽而不引依赖、复制为深拷贝（明确不做引用型共享区块）、跨页复制为何必须走服务端行锁、模板表设计、props 兼容合并、选择集用 id 而非索引、模板不加入素材扫描的原因、体积上限
- `tasks.md` — 33 项任务，分 6 组

## 明确排除（按你的选择）

- 全局共享区块（一处修改全站生效）——需要引用模型与失效传播，另案
- 撤销/重做栈、区块嵌套分组、页面级模板一键铺页、模板审核与个人可见范围
- 定时发布（在 `page-publication-approval` 中也已排除）
